CRITICAL UX REQUIREMENT
---------------------------------------------------

The application must support TWO PRIMARY OPERATING MODES:

1. Internal Enterprise / CIO View
2. Consulting / Services Company View

The user must be able to SWITCH between these views using a GLOBAL VIEW SWITCHER DROPDOWN at the top navigation bar.

Example dropdown:
[ Internal Enterprise ▼ ]
[ Consulting Services ▼ ]

When switching views:
- dashboards change
- KPIs change
- sidebar navigation changes
- workflows change
- metrics change
- executive summaries change
- modules shown change

This is still ONE CODEBASE and ONE PLATFORM.

The platform should behave like:
- role-aware
- tenant-aware
- mode-aware
- dynamically rendered based on active operating model
